# CA-02 — Assistant message anatomy: work row, prose, report, next step

*Blocked by: CA-01 · Spec: §Message anatomy*

## What to build
The Drive reply as a chat message: collapsible work row ("Worked for 1.1 s · Checked 9 things",
live shimmer with the current tool while streaming; rows per tool with inputs/outputs; separate
"Thinking (unchecked)"), the verdict sentence as prose with citation superscripts, then the report
card (verdict word + 4 numbers + Map version), "What I asked last time", readback line, Next step
card (drive recipe / gauge table / nothing), quick-reply chips under the latest message.

## Acceptance
- [ ] Upload a Drive → while running: "Reading your log…" shimmer naming the current step.
- [ ] Done → one collapsed row; click → each step; click a step → inputs and output.
- [ ] Prose first; cards below in decision order; nothing duplicated (window line once).
- [ ] Verdict always shows its word, not only a colour.
