# CA-05 — Options → Plan → Flash → Verify as turns

*Blocked by: CA-02*

## What to build
- **Options card** from `flashPlan.levers` + headline: what can change now (selectable) and what
  is locked with its reason and what unlocks it. "No map change" says so as an answer.
- **Plan card**: numbered overview (open file · change N cells in K tables · save as · flash · log
  the proof drive), then the KTuner card (tables, rows, "N of 16", before → after, tick list, copy
  row), undo file, readback note.
- **Flash turn**: "I flashed it" / "Not now" (and Undo "I flashed it back") post as the owner's
  message; the assistant replies with the result line, the Shakedown rule and the proof-drive
  recipe; sidebar Map version updates.

## Acceptance
- [ ] A Drive with a one-family plan → options card → plan card → tick all → I flashed it → user bubble + "Map version 2 is now on your car" + Shakedown recipe.
- [ ] Not now → "Nothing was saved" as an assistant message.
- [ ] Locked levers are visible but not tappable, each says what unlocks it.
