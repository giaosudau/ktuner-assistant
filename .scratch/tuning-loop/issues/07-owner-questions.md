# 07 — Owner questions: pause, answer, resume

**What to build:** when only the owner knows a fact, the reply asks it as tap-to-answer choices, the graph pauses (LangGraph interrupt, CopilotKit interrupt UI), and the answer resumes it with the Next step updated. Questions are generated by the engine, never the model. Answers are saved and applied through engine operations at their point in time (record a Flash before the Drive it explains; answer an Unexplained change after it), then the Car history is re-derived.

First questions:
- **What changed** (at a trims Stop after a change): flashed with MAF Scaling changed / flashed something else / fitted a part, no flash / nothing I know of.
- **Which intake housing** (only when the Flash plan routes to the MAF Scaling choice): factory airbox / PRL HVI / PRL Race housing / 27WON Race / not sure.
- **Did you flash** (after-flash Knock Control pattern with an open Stop): yes, the old file back (Undo) / yes, a different file / no.

The housing answer only resolves the Flash plan's own route, shown inside the KTuner box: factory airbox → Factory; PRL HVI → Factory, proven by the next calm Drive's trims; PRL Race housing → PRL Race; 27WON Race → 27Won Race; not sure → stay on the Undo file.
